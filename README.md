# Muhammed Shamal K — Portfolio Website

A responsive static portfolio website inspired by the clean editorial structure and orange/black visual direction of the reference site shared by the user: https://dmirsha.com/

## Files
- `index.html` — page content
- `style.css` — responsive styling
- `script.js` — mobile menu + scroll reveal
- `assets/profile.jpg` — profile photo

## Before publishing
Replace these placeholders in `index.html`:
- `YOUR_EMAIL@example.com`
- `YOUR_NUMBER`
- Instagram URL
- LinkedIn URL
- project image placeholders

## GitHub Pages
1. Create a new GitHub repository, e.g. `shamal-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. In GitHub: **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide your live Pages URL.

To use `mhdshamal.in`, configure a custom domain in GitHub Pages after your site is live.
